# Benchmarks (Objective 8 — Rigorous Evaluation)

STUB. This directory will hold:
- A benchmark suite of ~15-20 real-world workflows.
- Baselines: manual execution and a traditional RPA tool, for comparison.
- Scripts that compute: task success rate, latency, cost per workflow, and
  human intervention rate, for the agentic system vs. both baselines.

Cannot be meaningfully built until Objectives 2-5 (tools, memory,
orchestration engine, recovery loop) exist, since the benchmark needs real
tool executions, not mocks, to produce trustworthy numbers.
